# Походы Наполеона Бонапарта · 1793–1815

Интерактивная карта для урока истории (8 класс).

## Как открыть
Дважды щёлкните по файлу `index.html` — сайт откроется в браузере (лучше Chrome или Edge).
Интернет не нужен: карта, шрифты и библиотеки лежат в папке проекта.

## Что умеет сайт
- **Шкала времени** внизу: ползунок, кнопка ▶ (анимация завоеваний), скорость 1×/2×/4×, переход к предыдущему/следующему событию.
- **37 событий и сражений** на карте: щелчок открывает полную страницу (ход событий, силы и потери, стороны, итоги, факт, цитата, мини-карта Европы в момент события, озвучка).
- **Экскурсия** — автоматический тур с рассказчиком (голос браузера) по 24 ключевым событиям.
- **1812: график Минара** — знаменитая инфографика гибели Великой армии с графиком мороза.
- **Викторина** — 10 вопросов: «найди место на карте» и вопросы с вариантами ответа, итоговое звание.
- **Летопись событий** — все события списком с фильтрами («С участием России», «Сражения», «Победы»…).

Клавиши: пробел — пуск/пауза, ← / → — предыдущее/следующее событие, Esc — закрыть.

Границы государств показаны приблизительно; численность войск и потери — по средним оценкам историков.
